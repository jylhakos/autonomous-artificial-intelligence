# samples/adk — Google Agent Development Kit Memory Samples

This directory contains Python samples that demonstrate **short-term** and
**long-term** memory in AI agents using the
[Google Agent Development Kit (ADK)](https://adk.dev/).

## Files

| File | Concept demonstrated |
|------|---------------------|
| `short_term_memory.py` | Session state (ephemeral, within one conversation) |
| `long_term_memory.py` | MemoryService (persistent, across sessions) |

See the top-level [README.md](../../README.md) for full setup instructions.
